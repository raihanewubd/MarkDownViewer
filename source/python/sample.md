# Welcome to Markdown Viewer

This is a **rendered document** with *emphasis* and ~~strikethrough~~.

## Features

- Open a file with **Ctrl+O** or drag it into the window.
- Toggle raw Markdown with **Ctrl+U**.
- Find text with **Ctrl+F**.
- Switch theme with **Ctrl+D**.

| View | Purpose |
| --- | --- |
| Rendered | Read the formatted document |
| Source | Inspect the original Markdown |
